# 🌈 My Happy To-Do List

A colorful and child-friendly To-Do List web application designed for students from 5th to 10th standard.

The application helps students organize their daily activities, track completed tasks, and stay motivated through a simple points and progress system.

## ✨ Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- ⭐ Earn points for completed tasks
- 📊 View task progress
- 😊 Filter All, Active, and Completed tasks
- 🎨 Automatic icons based on task type
- 🎉 Motivational completion messages
- 💾 Save tasks using browser Local Storage
- 📱 Responsive design for mobile and desktop
- 🌈 Colorful and child-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
